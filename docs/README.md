# The Good Book

This is an open-source project for building a Bible-reading app focused on bringing the best possible experience in a universal app that provide the same experience on all platforms.

## Technology stack

Currently, the app is a Next.js app router app. Due to limited offline capabilities and a more server-focused orientation and the requirements of the app deviating from Next's ethos, I decided to migrate the existing implementation to Tanstack start which seemed to be fit better. It offers very good SSR support while also being very client oriented.
